This is the **structure only**: every folder and file of the real project, with no code.
Each file says what it does, who owns it, and what to read first. Each folder has a README.

Use it to learn your way around before touching the real repository.

## Start here, in this order

1. **This file** - five minutes.
2. **OWNERSHIP.md** - find your area and your files.
3. **BRANCHING.md** - how we use git, and the rules that keep merges painless.
4. **TASKS.md** - your branches and what each one delivers.
5. **CONFLICTS.md** - the shared files, and the one rule that prevents 90% of conflicts.
6. **docs/RootBridge-Course-Book.pdf** (in the real repo) - every file explained line by line.

## What the project is

A heritage-language learning platform. Families, independent learners and teachers use
one app for different purposes.

- **Backend:** Node.js, Express, MongoDB with Mongoose, bcrypt, JWT
- **Frontend:** React 19, Vite, React Router 7, plain CSS
- **Content:** four languages, 8 tracks, 37 chapters, 134 modules, 536 lessons
- **Deployment:** one web service serves both the API and the built website
