# frontend/src/components

Pieces of interface used by more than one page: the lesson player, the speaking button, the navbar, dialogs, cards and banners. A component draws something and manages its own small state.

## Files in this folder

- **ErrorBoundary.jsx** (Member 5) - Catches a crash while drawing and shows a friendly screen.
- **FindClass.jsx** (Member 3) - Lets a learner with no code find a teacher and ask to join.
- **Footer.jsx** (Member 5) - Site footer.
- **ForgotPin.jsx** (Member 1) - Recovering a forgotten parent PIN with the account password.
- **GlobeScene.jsx** (Member 5) - The decorative globe on the home page.
- **JoinClassCard.jsx** (Member 3) - The six-box code entry.
- **Layouts.jsx** (Member 5) - Page frames.
- **LessonEngine.jsx** (Member 2) - The lesson player: it draws every exercise kind, checks answers, handles hints, hearts and audio, and reports the result.
- **LiveClassBanner.jsx** (Member 3) - A slim banner on the dashboard when a class has a live link.
- **LivesBar.jsx** (Member 2) - Draws the hearts.
- **Navbar.jsx** (Member 5) - The top bar: links for the current role, the hearts, the view switch and the profile.
- **OutOfLives.jsx** (Member 2) - What a learner sees at zero hearts: two honest ways back.
- **PinDialog.jsx** (Member 1) - Asks for the four-digit parent PIN.
- **ProgressBar.jsx** (Member 5) - A labelled progress bar.
- **PushToTalk.jsx** (Member 2) - Speaking practice: listens with the browser, then has the server grade it.
- **ScrollToTop.jsx** (Member 5) - Scrolls to the top when the address changes.
- **TrackOff.jsx** (Member 5) - Shown when a parent has switched a track off.
- **ViewSwitch.jsx** (Member 5) - The child/parent switch for family accounts.
