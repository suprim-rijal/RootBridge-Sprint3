# frontend/src/lib

Logic that is not a component: progress (saved locally and synced), hearts, building lesson exercises, speaking words aloud, and the dashboard summary numbers.

## Files in this folder

- **exercises.js** (Member 2) - Builds the practice steps of a lesson.
- **image.js** (Member 5) - Shrinks a chosen photo in the browser before it is ever sent.
- **learningSummary.js** (Member 5) - Turns raw progress into the numbers the dashboard shows.
- **lives.js** (Member 2) - The hearts as seen by the browser: one shared value, always from the server.
- **progress.js** (Member 2) - Learner progress: instant in the browser, synced to the server in the background.
- **speech.js** (Member 2) - Speaking words aloud with the browser's own voices.
