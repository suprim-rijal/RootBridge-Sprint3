# frontend/src/pages

One file per screen, grouped by area (auth, dashboard, learn, parent, teacher, profile). A page fetches what it needs, composes components, and decides what an action means.

## Folders inside

- `auth/`
- `dashboard/`
- `learn/`
- `parent/`
- `profile/`
- `teacher/`

## Files in this folder

- **About.jsx** (Member 5) - The public About page: what RootBridge is for and who built it.
- **Contact.jsx** (Member 5) - The contact form.
- **Home.jsx** (Member 5) - The public landing page.
- **NotFound.jsx** (Member 5) - The 404 page.
