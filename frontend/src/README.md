# frontend/src

All the frontend source. main.jsx starts React, App.jsx maps every address to a page, and everything else is grouped by what it does.

## Folders inside

- `components/`
- `config/`
- `context/`
- `data/`
- `lib/`
- `pages/`
- `routes/`
- `services/`
- `styles/`

## Files in this folder

- **App.css** (Member 5) - Part of the visual theme, written with the colour and spacing variables defined in index.css.
- **App.jsx** (Member 5) - The map of the whole website: which address shows which page, and which guard protects it.
- **index.css** (Member 5) - Part of the visual theme, written with the colour and spacing variables defined in index.css.
- **main.jsx** (Member 5) - The very first file the browser runs: it attaches React to the page.
